# AI Web Scraper & Sentiment Analysis Dashboard

An end-to-end Python application that scrapes web data, performs NLP-based sentiment analysis and keyword extraction, stores enriched records in SQLite, and displays the results through a Flask dashboard.

## 🚀 Features

- Web scraping using Requests and BeautifulSoup
- NLP-based sentiment analysis using TextBlob
- Polarity and subjectivity analysis
- Lightweight keyword extraction
- SQLite database storage
- Search and sentiment filtering
- CSV export
- Flask-based web dashboard

## 🛠️ Tech Stack

- Python
- Flask
- TextBlob
- BeautifulSoup
- Requests
- Pandas
- SQLite
- HTML/CSS
